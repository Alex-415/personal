show your Worker URL.\n\n**Check 2: View logs**\n```bash\nwrangler tail\n```\n\nLook for errors.\n\n**Check 3: Test health**\n```bash\ncurl https://YOUR_WORKER_URL/\n```\n\nShould return:\n```json\n{\"status\":\"ok\",\"service\":\"openclaw-experience\"}\n```\n\n### Problem: Webhook Error\n\n**Error: \"Webhook was not set\"**\n- ❌ Bot token is wrong\n- ❌ Worker URL is wrong\n- ❌ Worker URL is HTTP (should be HTTPS)\n- ❌ Worker is not deployed\n\n**Solution:**\n- ✅ Double-check bot token\n- ✅ Double-check Worker URL\n- ✅ Ensure URL starts with HTTPS\n- ✅ Verify Worker is deployed\n\n### Problem: Slow Response\n\n**Possible causes:**\n- Gemini API is slow\n- Web search is slow\n- Worker is cold starting\n\n**Solution:**\n- Wait a few seconds\n- Try simpler query\n-

# 🚀 Run openClaw experience Locally - Step by Step\n\n## Prerequisites\n\n✅ Node.js 18+ installed\n✅ npm installed\n✅ Telegram account\n✅ Google account\n\n---\n\n## Step 1: Get Your API Keys (5 minutes)\n\n### Telegram Bot Token\n1. Open Telegram\n2. Search for `@BotFather`\n3. Send `/newbot`\n4. Follow prompts\n5. Copy your token (format: `123456:ABC-DEF1234...`)\n\n### Google Gemini API Key\n1. Visit https://ai.google.dev/\n2. Click \"Get API Key\"\n3. Create new API key\n4. Copy the key\n\n**Keep these keys safe - you'll need them in Step 3**\n\n---\n\n## Step 2: Run Setup Script (2 minutes)\n\n```bash\n# Navigate to the personal-website directory\ncd \"/Users/mac/Desktop/personal website/personal-website\"\n\n# Make setup script executable\nchmod +x setup-local.sh\n\n# Run the setup script\n./setup-local.sh\n```\n\nThe script will:\n- ✅ Check prerequisites\n- ✅ Create project directory\n- ✅ Copy and rename files\n- ✅ Install dependencies\n- ✅ Create configuration files\n- ✅ Set up local database\n\n---\n\n## Step 3: Add Your API Keys (1 minute)\n\n```bash\n# Navigate to project\ncd openclaw-experience\n\n# Edit .env.local\nnano .env.local\n```\n\nReplace:\n```\nTELEGRAM_BOT_TOKEN=your_telegram_bot_token_here\nGEMINI_API_KEY=your_google_gemini_api_key_here\n```\n\nWith your actual keys from Step 1.\n\nSave: `Ctrl+O`, `Enter`, `Ctrl+X`\n\n---\n\n## Step 4: Start Development Server (1 minute)\n\n```bash\n# Make sure you're in the openclaw-experience directory\ncd openclaw-experience\n\n# Start the development server\nwrangler dev\n```\n\nYou should see:\n```\n⛅ wrangler 3.x.x\n▲ [wrangler:dev] Starting local server...\n▲ [wrangler:dev] Listening on http://localhost:8787\n```\n\n**Keep this terminal open!**\n\n---\n\n## Step 5: Open New Terminal - Watch Logs\n\n```bash\n# In a NEW terminal window\nwrangler tail\n```\n\nYou should see:\n```\n▲ [wrangler:tail] Connected\n```\n\n**Keep this terminal open to see logs!**\n\n---\n\n## Step 6: Open New Terminal - Test It\n\n```bash\n# In a NEW terminal window\n\n# Test health check\ncurl http://localhost:8787/\n\n# Should return:\n# {\"status\":\"ok\",\"service\":\"openclaw-experience\"}\n```\n\n---\n\n## Step 7: Send Your First Message\n\n```bash\n# In the same terminal as Step 6\n\ncurl -X POST http://localhost:8787/webhook \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"message\": {\n      \"message_id\": 1,\n      \"date\": 1234567890,\n      \"chat\": {\"id\": 123456789, \"type\": \"private\"},\n      \"from\": {\"id\": 123456789, \"is_bot\": false, \"first_name\": \"Test\"},\n      \"text\": \"Hello! What can you do?\"\n    }\n  }'\n```\n\nYou should see:\n```\n{\"ok\":true}\n```\n\nCheck Terminal 2 (logs) to see what happened!\n\n---\n\n## Step 8: Check Your Database\n\n```bash\n# In the same terminal as Step 6\n\n# View all messages\nwrangler d1 execute openclaw-db --local --command \"SELECT * FROM chat_history\"\n\n# Should show your test message\n```\n\n---\n\n## Step 9: Run Automated Tests\n\n```bash\n# In the same terminal as Step 6\n\n# Go back to personal-website directory\ncd ..\n\n# Run tests\nbash test-openclaw-local.sh\n```\n\nThis will:\n- ✅ Test health check\n- ✅ Send simple message\n- ✅ Send search query\n- ✅ Send follow-up message\n\n---\n\n## 🎉 You're Running Locally!\n\n### Your Setup\n\n```\nTerminal 1: wrangler dev (http://localhost:8787)\nTerminal 2: wrangler tail (logs)\nTerminal 3: curl commands (testing)\nTerminal 4: Database queries\n```\n\n### What You Can Do Now\n\n✅ Send messages via curl\n✅ Watch logs in real-time\n✅ Query the database\n✅ error\n```bash\nwrangler d1 create openclaw-db --local\nwrangler d1 execute openclaw-db --local --file=src/db/schema.sql\n```\n\n### API key errors\n- Check `.env.local` has correct keys\n- Verify keys are not expired\n- Check Google Cloud Console has API enabled\n\n### No response from webhook\n```bash\n# Check logs\nwrangler tail\n\n# Test health\ncurl http://localhost:8787/\n\n# Verify

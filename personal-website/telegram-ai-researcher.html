24/7 personal AI assistant on Telegram. Searches the web, summarizes content, and remembers conversation context. Built entirely on Cloudflare's free tier.

Overview

A production-grade AI research assistant deployed as a Telegram bot. The bot runs 24/7 on Cloudflare Workers, uses Google Gemini for intelligence, stores conversation history in Cloudflare D1, and performs web searches via DuckDuckGo. Everything runs on free tiers with zero infrastructure costs.

Key Features

🤖 AI-Powered Responses

Uses Google Gemini 1.5 Flash for fast, intelligent responses to natural language queries.

🌐 Web Search Integration

Automatically searches the web for current information when needed, with DuckDuckGo integration.

💾 Conversation Memory

Stores last 10 messages in Cloudflare D1 for context-aware responses across sessions.

⚡ Serverless & Scalable

Runs on Cloudflare Workers with automatic scaling. No servers to manage, no cold starts.

🔒 Secure & Private

Uses Worker Bindings for database access (no API keys exposed). All data encrypted in transit.

💰 Zero Cost

Runs entirely on free tiers: Cloudflare Workers, D1, Telegram Bot API, and Google Gemini free tier.

How It Works

  1. User sends message to Telegram bot → Telegram forwards to Cloudflare Worker webhook
  2. Worker retrieves conversation history → Queries last 10 messages from D1 database
  3. Worker determines if web search needed → Analyzes query to decide if current info required
  4. Optional web search → Fetches top 3 results from DuckDuckGo if needed
  5. LLM processing → Sends query + context + search results to Google Gemini
  6. Response generation → Gemini returns intelligent response
  7. Store in database → Saves user message and bot response to D1
  8. Send to Telegram → Returns response to user (within 30-second timeout)

Deployment Steps

  1. Create Cloudflare D1 database:
    wrangler d1 create telegram-bot-db
  2. Update wrangler.toml with the database ID from the output
  3. Apply database schema:
    wrangler d1 execute telegram-bot-db --file=src/db/schema.sql
  4. Set environment variables in Cloudflare dashboard or .env file
  5. Deploy Worker:
    wrangler deploy
  6. Set Telegram webhook to your Worker URL

Why This Stack?

  • Cloudflare Workers — Global edge network, instant scaling, no cold starts, free tier includes 100k requests/day
  • D1 Database — Native Cloudflare database, Worker Bindings (no API keys), 5GB free storage, SQLite simplicity
  • Google Gemini — Fast, free tier available, excellent for research tasks, no Elon Musk ties
  • Telegram Bot API — Completely free, webhook-based (no polling), reliable infrastructure
  • DuckDuckGo — No API key required, privacy-focused, good search results

Limitations & Considerations

  • 30-second timeout: Telegram expects responses within 30 seconds. Complex queries may timeout.
  • Free tier limits: Google Gemini free tier has rate limits (~60 requests/minute)
  • D1 storage: 5GB free tier is sufficient for millions of text messages
  • Worker limits: 100k requests/day free tier (sufficient for personal use)
  • Search results: Limited to 3 results per search to stay within rate limits

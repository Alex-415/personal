openClaw experience

AI assistant on Telegram. Searches the web, remembers context. Free tier.

Overview

Telegram bot on Cloudflare Workers. Uses Gemini for responses, D1 for chat history, DuckDuckGo for web search. Zero cost.

Features

🤖 Gemini AI

Fast responses using Gemini 1.5 Flash.

🌐 Web Search

DuckDuckGo integration for current info.

💾 Memory

Stores last 10 messages for context.

⚡ Serverless

Cloudflare Workers, auto-scaling.

🔒 Secure

Worker Bindings, encrypted data.

💰 Free

All free tiers, zero cost.

Architecture

Telegram Bot API ↓ Cloudflare Worker (Webhook) ├── ↔ Cloudflare D1 (Chat History) ├── ↔ Google Gemini API (LLM) └── ↔ DuckDuckGo Search (Web Results)

Tech Stack

Backend & Infrastructure

Cloudflare Workers
TypeScript
Hono Framework
Cloudflare D1
SQLite
Telegram Bot API

DuckDuckGo Search

How It Works

  1. Message sent to Telegram bot
  2. Worker retrieves last 10 messages from D1
  3. Checks if web search needed
  4. Searches DuckDuckGo if needed
  5. Sends to Gemini with context
  6. Saves message pair to D1
  7. Returns response to Telegram

Why This Stack?

  • Cloudflare Workers — Edge network, auto-scaling, 100k requests/day free
  • D1 — Native database, Worker Bindings, 5GB free
  • Gemini — Fast, free tier, no Elon ties
  • Telegram — Free, webhook-based
  • DuckDuckGo — No API key, privacy-focused

Limits

  • 30-second Telegram timeout
  • Gemini: ~60 requests/minute
  • Workers: 100k requests/day
  • Search: 3 results per query

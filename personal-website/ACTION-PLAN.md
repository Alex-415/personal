# 🎯 ACTION PLAN: Run openClaw experience Locally\n\n## ⏱️ Time Required: ~15 minutes\n\n---\n\n## 📋 STEP-BY-STEP\n\n### STEP 1: Get API Keys (5 minutes)\n\n#### Telegram Bot Token\n1. Open Telegram app\n2. Search for: `@BotFather`\n3. Send: `/newbot`\n4. Follow the prompts\n5. Copy your token (looks like: `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`)\n6. **Save it somewhere safe**\n\n#### Google Gemini API Key\n1. Open browser: https://ai.google.dev/\n2. Click: \"Get API Key\"\n3. Create new API key\n4. Copy the key (looks like: `AIzaSyD...`)\n5. **Save it somewhere safe**\n\n---\n\n### STEP 2: Run Setup Script (2 minutes)\n\n**Copy and paste this into Terminal:**\n\n```bash\ncd \"/Users/mac/Desktop/personal website/personal-website\"\nchmod +x setup-local.sh\n./setup-local.sh\n```\n\n**Wait for it to complete. You should see:**\n```\n✅ Setup Complete!\n```\n\n---\n\n### STEP 3: Add Your API Keys (1 minute)\n\n**Copy and paste this into the SAME Terminal:**\n\n```bash\ncd openclaw-experience\nnano .env.local\n```\n\n**You'll see a text editor. Find these lines:**\n```\nTELEGRAM_BOT_TOKEN=your_telegram_bot_token_here\nGEMINI_API_KEY=your_google_gemini_api_key_here\n```\n\n**Replace with your actual keys from STEP 1:**\n```\nTELEGRAM_BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11\nGEMINI_API_KEY=AIzaSyD...\n```\n\n**Save the file:**\n- Press: `Ctrl+O`\n- Press: `Enter`\n- Press: `Ctrl+X`\n\n---\n\n### STEP 4: Start Development Server (1 minute)\n\n**Copy and paste this into the SAME Terminal:**\n\n```bash\nwrangler dev\n```\n\n**You should see:**\n```\n⛅ wrangler 3.x.x\n▲ [wrangler:dev] Starting local server...\n▲ [wrangler:dev] Listening on http://localhost:8787\n```\n\n**✅ KEEP THIS TERMINAL OPEN!**\n\n---\n\n### STEP 5: Open NEW Terminal - Watch Logs\n\n**Open a NEW terminal window and copy-paste:**\n\n```bash\nwrangler tail\n```\n\n**You should see:**\n```\n▲ [wrangler:tail] Connected\n```\n\n**✅ KEEP THIS TERMINAL OPEN!**\n\n---\n\n### STEP 6: Open NEW Terminal - Test It\n\n**Open a NEW terminal window and copy-paste:**\n\n```bash\ncurl http://localhost:8787/\n```\n\n**You should see:**\n```json\n{\"status\":\"ok\",\"service\":\"openclaw-experience\"}\n```\n\n✅ **If you see this, it's working!**\n\n---\n\n### STEP 7: Send Your First Message\n\n**Copy and paste this into the SAME terminal (from STEP 6):**\n\n```bash\ncurl -X POST http://localhost:8787/webhook \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"message\": {\n      \"message_id\": 1,\n      \"date\": 1234567890,\n      \"chat\": {\"id\": 123456789, \"type\": \"private\"},\n      \"from\": {\"id\": 123456789, \"is_bot\": false, \"first_name\": \"Test\"},\n      \"text\": \"Hello! What can you do?\"\n    }\n  }'\n```\n\n**You should see:**\n```json\n{\"ok\":true}\n```\n\n✅ **Check Terminal 2 (logs) to see what happened!**\n\n---\n\n### STEP 8: Check Your Database\n\n**Copy and paste this into the SAME terminal (from STEP 6):**\n\n```bash\nwrangler d1 execute openclaw-db --local --command \"SELECT * FROM chat_history\"\n```\n\n**You should see your message stored:**\n```\nid | user_id | user_message | bot_response | created_at\n1  | 123     | Hello!...    | Hi there!... | 2024-01-15...\n```\n\n✅ **Your message is stored in the database!**\n\n---\n\n### STEP 9: Run Automated Tests\n\n**Copy and paste this into the SAME terminal (from STEP 6):**\n\n```bash\ncd ..\nbash test-openclaw-local.sh\n```\n\n**This will run 4 tests:**\n- ✅ Health check\n- ✅ Simple message\n- ✅ Search query\n- ✅ Follow-up message\n\n---\n\n## 🎉 YOU'RE RUNNING LOCALLY!\n\n### Your Setup\n\n```\nTerminal 1: wrangler dev (http://localhost:8787)\n            ↓\n            Your local Worker running\n            ↓\nTerminal 2: wrangler tail\n            ↓\n            Real-time logs\n            ↓\nTerminal 3: curl commands\n            ↓\n            Testing\n```\n\n---\n\n## 📝 What You Can Do Now\n\n### Edit Code\n```bash\n# Edit any file in openclaw-experience/src/\n# Changes auto-reload in Terminal 1\n```\n\n### Send More Messages\n```bash\n# Terminal 3\ncurl -X POST http://localhost:8787/webhook ...\n```\n\n### View Logs\n```bash\n# Terminal 2 shows all logs in real-time\n```\n\n### Query Database\n```bash\n# Terminal 3\nwrangler d1 execute openclaw-db --local --command \"SELECT * FROM chat_history\"\n```\n\n---\n\n## 🔄 Development Workflow\n\n```\n1.

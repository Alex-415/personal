# 🤖 openClaw experience - Get Working on Telegram\n\n## 🎯 What You Need\n\n✅ Deployed to Cloudflare (you have this)\n✅ Gemini API key added (you have this)\n✅ Telegram bot token (you have this)\n✅ Your Worker URL (you need this)\n\n---\n\n## 📋 Step 1: Get Your Worker URL\n\n### From Cloudflare Dashboard\n1. Go to: https://dash.cloudflare.com/\n2. Click: \"Workers & Pages\"\n3. Click: \"openclaw-experience\" (your worker)\n4. Copy the URL (looks like: `https://openclaw-experience.your-account.workers.dev`)\n\n### Or From Terminal\n```bash\nwrangler deployments list\n```\n\nLook for the URL in the output.\n\n**Save this URL - you'll need it!**\n\n---\n\n## 🔗 Step 2: Set Telegram Webhook\n\n### Option A: Using curl (Recommended)\n\n```bash\n# Replace YOUR_BOT_TOKEN with your actual token\n# Replace YOUR_WORKER_URL with your actual Worker URL\n\ncurl -X POST https://api.telegram.org/botYOUR_BOT_TOKEN/setWebhook \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"url\": \"YOUR_WORKER_URL/webhook\"}'\n```\n\n**Example:**\n```bash\ncurl -X POST https://api.telegram.org/bot123456:ABC-DEF1234/setWebhook \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"url\": \"https://openclaw-experience.myaccount.workers.dev/webhook\"}'\n```\n\n### Option B: Using Python\n\n```python\nimport requests\n\nbot_token = \"YOUR_BOT_TOKEN\"\nworker_url = \"YOUR_WORKER_URL\"\n\nurl = f\"https://api.telegram.org/bot{bot_token}/setWebhook\"\ndata = {\"url\": f\"{worker_url}/webhook\"}\n\nresponse = requests.post(url, json=data)\nprint(response.json())\n```\n\n### Option C: Using Browser\n\n1. Open this URL in your browser (replace tokens):\n```\nhttps://api.telegram.org/botYOUR_BOT_TOKEN/setWebhook?url=YOUR_WORKER_URL/webhook\n```\n\n2. You should see:\n```json\n{\"ok\":true,\"result\":true,\"description\":\"Webhook was set\"}\n```\n\n---\n\n## ✅ Step 3: Verify Webhook is Set\n\n```bash\n# Replace YOUR_BOT_TOKEN with your actual token\n\ncurl https://api.telegram.org/botYOUR_BOT_TOKEN/getWebhookInfo\n```\n\n**You should see:**\n```json\n{\n  \"ok\": true,\n  \"result\": {\n    \"url\": \"https://openclaw-experience.myaccount.workers.dev/webhook\",\n    \"has_custom_certificate\": false,\n    \"pending_update_count\": 0,\n    \"ip_address\": \"...\",\n    \"last_error_date\": 0,\n    \"max_connections\": 40\n  }\n}\n```\n\n✅ If you see your URL, the webhook is set!\n\n---\n\n## 🤖 Step 4: Test on Telegram\n\n### Find Your Bot\n1. Troubleshooting\n\n### Bot Not Responding\n\n**Check 1: Webhook is set**\n```bash\ncurl https://api.telegram.org/botYOUR_TOKEN/getWebhookInfo\n```\n\nShould show your Worker URL.\n\n**Check 2: View logs**\n```bash\nwrangler tail\n```\n\nLook for errors.\n\n**Check 3: Test health endpoint**\n```bash\ncurl https://YOUR_WORKER_URL/\n```\n\nShould return:\n```json\n{\"status\":\"ok\",\"service\":\"openclaw-experience\"}\n```\n\n### Webhook Error\n\n**Error: \"Webhook was not set\"**\n- Check bot token is correct\n- Check Worker URL is correct\n- Check Worker URL is HTTPS (not HTTP)\n- Check Worker is deployed\n\n**Error: \"Webhook is not accessible\"**\n- Check Worker URL is accessible\n- Check firewall isn't blocking\n- Try again in a few seconds\n\n### Bot Responds Slowly\n\n**Possible causes:**\n- Gemini API is slow\n- Web search is slow\n- Worker is cold starting\n\n**Solution:**\n- Wait a few seconds\n- Check logs for errors\n- Try simpler query\n\n### Bot Responds with Error\n\n**Check logs:**\n```bash\nwrangler tail\n```\n\nLook for:\n- API key errors\n- Database errors\n- Timeout errors\n\n**Common fixes:**\n- Verify API keys are correct\n- Check Gemini API is enabled\n- Check rate limits\n\n---\n\n## 🔄 How It Works\n\n```\n1. You send message on Telegram\n   ↓\n2. Telegram sends to your Worker webhook\n   ↓\n3. Worker receives message\n   ↓\n4. Worker queries D1 database for conversation history\n   ↓\n5.
